## 📌 Executive Summary
**Krishna Trading** is a commercial B2B bulk manufacturer, supplier, and exporter of heavy industrial packaging materials (WPP Sacks, Kanta Bags, Plastic Packaging Bags, Corrugated Master Boxes).

**KTMS / Krishna Trading ERP** is a production-grade enterprise system featuring:
- 📁 **`ktms_backend/`**: Headless Django REST Framework (DRF) Backend with 21 PostgreSQL Database Schemas, Multi-Tenant Security Engine, and Smart Freight Weight Recommendation Engine.
- 📁 **`ktms_frontend/`**: Flutter Multi-Platform Web & Mobile App Suite for Super Admin, General Manager, Fleet Manager, Shop Staff, Drivers, Retail B2C, and Wholesale B2B Customers.
